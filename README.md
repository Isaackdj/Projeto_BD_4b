# 🏆 Liga Oficial Etec - Projeto de Banco de Dados

Projeto desenvolvido pelos alunos Isaac Galvão e João Gabriel, do **2º DS da Etec São José dos Campos**, sob a orientação do **Professor Jean**, como avaliação para a menção do 4º bimestre.

O sistema consiste em uma plataforma web para inscrição de times em um campeonato oficial da Etec, contando com integração entre front-end, back-end em Python e banco de dados MySQL.

---

## 🖥️ Telas do Sistema

O projeto possui uma interface dividida em 3 páginas principais:

1. **Home / Tela Inicial:** Uma página chamativa apresentando o campeonato **"Liga oficial Etec"** com destaque visual e um botão interativo *"Inscreva-se"*.
2. **Formulário de Inscrição:** Um formulário onde o usuário preenche os dados do clube/time para realizar o cadastro na liga.
3. **Chaveamento (Mata-Mata):** Tela que exibe a estrutura do campeonato em formato de mata-mata, mostrando os times cadastrados na liga.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Front-end:** HTML5, CSS3 (para a estruturação e estilização das 3 telas)
* **Back-end:** Python
* **Banco de Dados:** MySQL
* **Controle de Versão:** Git e GitHub
